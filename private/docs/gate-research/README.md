# Research-profile evidence

This evidence area governs class-based research profiles that are deliberately
separate from the historically compatible vSPD formulations and numbered
delivery gates.

The current evidence covers:

- the preregistered, hash-bound historical stress-event atlas; and
- the analytic `pyspd-multiperiod-battery-v1` formulation.

Passing these contracts establishes their stated research-foundation behavior.
It does not qualify the battery profile against historical vSPD, CPLEX, network,
reserve, or published-price outputs.

The machine-auditable red/green records are in [`tdd/`](tdd/README.md).
