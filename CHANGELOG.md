# Release notes

## 0.1.0 — unreleased engineering candidate

- Apache License 2.0 for PySPD, included in source and wheel distributions.
- Class-based vSPD v5 and SPD v16 formulations with explicit input schemas.
- Native SCIP dispatch followed by fixed-discrete HiGHS pricing.
- Independent validation, deterministic reports, and independent-case workers.
- Audited scenario API and a separate analytic battery research profile.
- Installable GDX, CLP, CBC, and Probity extras; HiGHS included by default.
- Build-lock provenance included in wheels for report generation outside a checkout.
- Explicit distribution file lists exclude internal documentation and external data.
- User documentation uses the same Sphinx Read the Docs theme as OpenPinch.

Qualification is scoped to Python 3.13 and macOS ARM64. Complete historical
parity and third-party redistribution decisions remain outstanding. This
candidate is not a published release.
